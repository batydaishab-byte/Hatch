# صور واجهات تطبيق HATCH Android Native

ارفع لقطات الشاشة الحقيقية (PNG) الملتقطة مباشرة من جهاز أندرويد أو المحاكي إلى هذا المجلد بالأسماء الدقيقة التالية، وستظهر تلقائياً في صفحة المعاينة (`/preview/`) دون الحاجة إلى تعديل الكود:

| اسم الملف المطلوب | الواجهة |
| --- | --- |
| `01-swipe.png` | واجهة HATCH للتصفح السريع |
| `02-market.png` | واجهة السوق (متضمنة زري المتاجر والشركات) |
| `03-stores-companies.png` | دليل المتاجر والشركات والصفحات التجارية |
| `04-product-detail.png` | تفاصيل المنتجات |
| `05-profile.png` | الملف الشخصي |

## مواصفات مقترحة
- الصيغة: `PNG`
- النسبة: `9:16` (مثلاً `1080 × 2400` بكسل)
- التقط الصور من التطبيق الفعلي داخل `android-native/` ولا تستخدم صوراً مولدة أو وهمية.
